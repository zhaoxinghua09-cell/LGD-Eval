# 交付物 A · 公开基准测试建设方案

## 1. 现状证据（208 仓，只读）

- 测试/基准目录：uibc-core、lgd-engine、skillgate、skill-audit、evaluation-evidence、lgd-xverify 等含 tests 目录；兼容/互操作文件 18 个、回归 29 个、对抗关键词文件 9 个、覆盖率产物 4 个；结构化盲测/留出集 0 个。
- 证据局限：文件名为关键词信号，不等同测试有效；部分‘对抗’命中来自复核流程文本；覆盖率报告制品未见归档。

## 2. 测试集分层设计

| 层级 | 对象 | 内容 | 版本与发布 |
|---|---|---|---|
Agent 行为基准 | 端到端 Agent 任务 | 任务输入、期望行为、约束条件、通过判据 | 数据集独立版本号，与引擎解耦 |
Skill 基准 | 单个 Skill/连接器 | 入参校验、边界输入、输出契约、失败路径 | 随 Skill 目录版本化 |
MCP 基准 | MCP Server/工具 | 工具清单、schema、调用结果、错误处理、权限边界 | 按 Server 版本归档 |
对抗测试 | 注入/越权/绕过/越界 | 提示注入、权限提升、静默失败、数据外泄用例 | 标注难度与防护目标 |
兼容性测试 | 独立实现/跨版本 | 一致性断言、互操作样例、前向/后向兼容 | 与规则版本绑定 |
回归测试 | 历史缺陷修复 | 缺陷回放、快照、黄金样本、历史成绩对照 | 每规则版本留档 |

## 3. 机制要求

1. **盲测/留出集**：每个基准划分公开训练集与私有留出集；留出集不入库、不随仓库分发，评测时由受控环境加载；记录数据集版本与 split。
2. **覆盖率与有效性**：归档覆盖率报告（语句/分支/工具调用路径）；用变异检查或已知缺陷回放评估测试有效性，不以 CI 绿色代替覆盖充分性。
3. **版本管理**：测试集、规则、引擎三者分别版本化；用兼容矩阵记录组合；新增用例不得回溯改动历史成绩。
4. **可复现**：每个基准声明依赖、固定版本、运行命令与随机种子；制品含输入快照与输出哈希。
5. **授权与隐私**：真实案例须脱敏并标注授权来源；合成/模拟案例明确标注；禁止把未授权数据纳入公开基准。

## 4. 验收标准

- 核心基准可一键复跑，输出结构化结果与覆盖率；留出集机制存在且与公开集隔离；
- 每条用例关联规则版本、数据集版本与通过判据；历史评测可按版本回溯；
- 兼容/回归/对抗三类用例均有归档计数与代表性样例，外部可独立复现。
